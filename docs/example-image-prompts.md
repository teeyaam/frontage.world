# Frontage vehicle example photos — Nano Banana prompts

12 prompts, one vehicle per country. For each one:

1. Copy the prompt into Nano Banana.
2. Save the image you like with the **filename shown** (e.g. `EXV-AU.jpg`). JPG or PNG are both fine.
3. On frontage.world → Staff → Examples, press **Replace the old examples with the 12 vehicle examples** (this removes the old wall/window examples), then upload all 12 images at once. Each photo is matched to its listing by the filename.

Tips: keep landscape (4:3). Re-roll any image with stray text, logos or a readable number plate, or where the orange dashed frame is missing or wobbly. If the frame comes out too faint, add "the dashed frame must be clearly visible".
