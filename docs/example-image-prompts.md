# Frontage example listing photos — Nano Banana prompts

90 prompts, 3 per country. For each one:

1. Copy the prompt into Nano Banana.
2. Save the image you like with the **filename shown** (e.g. `EX-AU-1.jpg`). JPG or PNG are both fine.
3. When they are done, upload them all at once on frontage.world → Staff → Examples. Each photo is matched to its listing by the filename.

Tip: keep landscape (4:3). Re-roll any image with stray text or logos.
